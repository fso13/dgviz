# Техническое задание (ТЗ) на проект «Dependency Graph Visualizer with GitLab Integration»

## 1. Общее описание

**Название проекта:** Dependency Graph Visualizer (DGViz)

**Тип проекта:** Open-source Java-приложение (Desktop/CLI)

**Лицензия:** Apache License 2.0

**Целевая аудитория:**
- Java-разработчики, работающие с Maven и Gradle
- DevOps-инженеры, отвечающие за CI/CD
- Команды, использующие GitLab как основную платформу для репозиториев

**Проблема, которую решает проект:**
Разработчики тратят значительное время на анализ зависимостей проекта — поиск конфликтов версий, дубликатов библиотек, уязвимых транзитивных зависимостей. Существующие инструменты либо работают только локально, либо не интегрированы с GitLab, что затрудняет командную работу и автоматизацию.

**Ключевая ценность:**
Единый инструмент, который подключается к GitLab-репозиторию, извлекает зависимости Maven/Gradle, строит интерактивный граф и подсвечивает проблемы (конфликты версий, дубликаты, уязвимости) с возможностью автоматического запуска через GitLab CI.

1. Предоставить разработчикам визуальное представление зависимостей Java-проекта в реальном времени.

## 5. Интеграция с GitLab: детализация

### 5.1. GitLab Dependencies API

GitLab предоставляет API для получения списка зависимостей проекта, поддерживаемых Gemnasium (включая Maven и Gradle) .

**Endpoint:**
```
GET /projects/:id/dependencies?package_manager=maven,gradle
```

**Аутентификация:**
```
PRIVATE-TOKEN: <your_access_token>
```

**Пример ответа (адаптировано):**
```json
[
  {
    "name": "spring-core",
    "version": "5.3.20",
    "package_manager": "maven",
    "dependency_file_path": "pom.xml",
    "vulnerabilities": [
      {
        "name": "CVE-2022-22965",
        "severity": "critical",
        "cve": "CVE-2022-22965"
      }
    ],
    "licenses": [
      {
        "name": "Apache License 2.0",
        "url": "https://opensource.org/licenses/Apache-2.0"
      }
    ]
  }
]
```

**Ограничения API (по документации):**
- Возвращает только зависимости, проанализированные Gemnasium 
- По умолчанию 20 результатов на страницу, требуется пагинация 
- Для просмотра уязвимостей требуется доступ к Project Security Dashboard 

**Роль DGViz:** Использовать этот API как источник данных для визуализации, дополняя его локальным парсингом для получения полного графа транзитивных зависимостей (API GitLab даёт плоский список, не дерево).

### 5.2. GitLab CI шаблон

Проект должен предоставлять готовый `.gitlab-ci.yml` шаблон для запуска анализа в пайплайне:

```yaml
stages:
  - analyze

dependency-graph:
  stage: analyze
  image: eclipse-temurin:17-jre
  script:
    - curl -L -o dgviz.jar https://github.com/org/dgviz/releases/latest/download/dgviz.jar
    - java -jar dgviz.jar ci-check --gitlab-token $GITLAB_TOKEN --project $CI_PROJECT_ID --fail-on-conflict --fail-on-cvss 7
  artifacts:
    paths:
      - reports/dependency-graph.html
      - reports/dependency-graph.json
    expire_in: 30 days
  only:
    - merge_requests
    - main
```

### 5.3. Аутентификация и безопасность

- Personal Access Token передаётся через переменную окружения `GITLAB_TOKEN`
- Поддержка `CI_JOB_TOKEN` для внутренних проектов GitLab
- Токен не логируется и не сохраняется в отчётах
- Для Self-Managed GitLab — настройка базового URL через `--gitlab-url`

## 7. Критерии приёмки

1. **Функциональность:** Инструмент успешно анализирует тестовый multi-module Maven проект и тестовый Gradle проект, строит граф и корректно определяет конфликты версий.
2. **GitLab:** Успешная аутентификация и получение данных о проекте через GitLab API (проверено на GitLab.com и Self-Managed).
3. **CI:** Шаблон `.gitlab-ci.yml` корректно работает в реальном пайплайне GitLab, артефакты публикуются.
4. **Производительность:** Анализ проекта с 300 зависимостями выполняется ≤30 секунд.
5. **Документация:** README содержит инструкции по установке, настройке токена и запуску в CI.
6. **Тесты:** `./gradlew test` проходит с покрытием ≥70%.

## 8. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|------------|---------|-----------|
| Ограничения GitLab Dependencies API (только Gemnasium-поддерживаемые пакеты, пагинация) | Средняя | Среднее | Дополнять локальным парсингом; документировать ограничения |
| Парсинг Gradle через Tooling API требует загрузки JAR  | Высокая | Среднее | Использовать Idea Model без загрузки JAR для declared dependencies; документировать ограничения |
| Ложные срабатывания OWASP Dependency-Check  | Высокая | Низкое | Поддержка suppression-файлов; настраиваемые пороги |
| Сложность поддержки нескольких систем сборки | Средняя | Высокое | Плагинная архитектура; начать с Maven, затем Gradle |
