Установка (Docker Compose)

git clone https://github.com/fso13/dgviz.git
cd dgviz
docker compose up --build -d
  • App: http://localhost:8080 — admin / admin
  • Notifications: http://localhost:8082
  • Adminer: http://localhost:8081
В production сразу смените DGVIZ_ADMIN_PASSWORD и ключ API notifications.

Образы из GitHub Container Registry

После релизного тега образы публикуются в GHCR:

docker pull ghcr.io/fso13/dgviz:0.3.0
docker pull ghcr.io/fso13/dgviz-notifications:0.3.0

# latest указывает на последний релиз
docker pull ghcr.io/fso13/dgviz:latest

В docker-compose.yml можно заменить build: на image: ghcr.io/fso13/dgviz:<tag>.

Ключевые переменные

ПеременнаяНазначение
DGVIZ_DB_*PostgreSQL
DGVIZ_ADMIN_USER / PASSWORDBootstrap admin
DGVIZ_PUBLIC_BASE_URLБазовый URL для invite/ссылок в письмах
DGVIZ_INVITE_TTL_DAYSСрок invite (по умолчанию 2)
DGVIZ_NOTIFICATIONS_URL / API_KEYСвязь с сервисом уведомлений
NVD_API_KEY, SNYK_TOKENОпционально для sync
DGVIZ_SMTP_*SMTP для EMAIL-транспорта (notifications)

Часть значений также хранится в Admin → Settings (invite.ttl-days, invite.public-base-url, sync keys).

Пользователи и invite

  1. Admin → Users → Создать: username, display name, email, роль и флаги прав.
  2. Пароль не задаётся — уходит invite-ссылка.
  3. Пока пользователь не активировался, статус pending invite; можно Resend invite.

Группы и ACL

  1. Создайте группу и добавьте участников.
  2. Назначьте группу проекту.
  3. Репозитории проекта наследуют доступ группы.

Права canManageProjects / Repositories / Groups ограничивают админ-действия; чтение workspace всё равно требует членства в группе проекта (кроме ADMIN).

Репозитории (PLUGIN)

  1. Admin → Repositories → создать в доступном проекте.
  2. Скопировать repositoryId и scan token в Gradle-плагин / CI secrets.
  3. Опционально: access token GitLab/GitHub для создания issues и trigger pipeline.
POST /api/v1/repositories/{id}/scan
Header: X-DGViz-Token: <scan token>

CVE sync

Admin → CVE Sync: NVD, OSV, GHSA, Snyk. У каждого источника — enabled, cron, Run now. Расписание перезагружается без рестарта.

Уведомления

Сервис dgviz-notifications:

  • Admin → Notifications — конфиг EMAIL/TELEGRAM, тест, лог.
  • EMAIL нужен для invite и рассылки отчётов.
  • Поддерживаются HTML-письма и вложения (PDF/CSV/TXT).

Релизы

Пайплайн GitHub Actions на тег v*:

  1. Собирает Docker-образы dgviz и dgviz-notifications.
  2. Пушит в ghcr.io/fso13/… с тегами версии и latest.
  3. Создаёт GitHub Release и прикладывает bootJar.
# пример релиза
git tag v0.3.1
git push origin v0.3.1
