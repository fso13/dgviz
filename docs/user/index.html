Документация для пользователей

Как работать с проектами, репозиториями, сканами, экспортом и приглашениями.

Вход Доступ Workspace Сканы Экспорт и почта Приглашение Gradle-плагин

Вход

Откройте URL вашего DGViz и войдите логином/паролем. Если вас пригласили — сначала перейдите по ссылке из письма и задайте пароль.

Доступ к данным

Видимость строится так: пользователь ∈ группа ← проект ← репозиторий.

  • ADMIN видит все проекты и репозитории.
  • USER видит только проекты своей группы (и их репозитории).
  • Флаги «manage projects/repos/groups» дают права на админ-разделы, но не заменяют членство в группе.

Workspace

  • /workspace/projects — доступные проекты
  • /workspace/repositories — репозитории и статус последнего скана
  • Страница репозитория: обзор, дерево зависимостей, уязвимости, история сканов
  • /workspace/vulnerabilities — находки по доступным анализам + справочник CVE

Сканы

Данные появляются после ./gradlew dgvizScan в целевом проекте (или после pipeline в CI).

  • Пересканировать — повторный анализ уже сохранённого SBOM/дерева по актуальной CVE DB (плагин не нужен).
  • Обновить дерево (CI) — триггер GitLab pipeline, чтобы обновить состав зависимостей.

Экспорт и почта

На странице репозитория (если есть скан):

ДействиеФорматы
Дерево зависимостейTXT, CSV, JSON
УязвимостиCSV, XLSX, PDF
SBOMJSON (CycloneDX)
Отправить отчёт на почтуPDF + CSV + дерево всем участникам группы с email
Письмо уходит только enabled-пользователям группы проекта с заполненным email. Нужен включённый EMAIL-транспорт в notifications.

Приглашение (если вас добавили)

  1. Откройте ссылку из письма (действует по умолчанию 2 дня).
  2. Задайте пароль (минимум 8 символов).
  3. Войдите логином, который указал администратор.

Gradle-плагин (для разработчика репозитория)

plugins {
  id("io.github.dgviz.scan") version "0.3.0"
}
dgviz {
  host = "https://dgviz.example.com"
  repositoryId = 12
  token = System.getenv("DGVIZ_TOKEN") ?: ""
}

Задача: ./gradlew dgvizScan. Отчёты локально: build/reports/dgviz/.

Подробнее — в dgviz-gradle-plugin/README.md.
