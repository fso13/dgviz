DGViz

Платформа для анализа дерева зависимостей Maven/Gradle: CVE, конфликты версий, отчёты и интеграция с GitLab CI — без выгрузки исходников.

✗ 3 HIGH / 1 CRITICAL CVE

report → build/reports/dgviz/

Что умеет

Сервер + Gradle-плагин: сканируете в CI, смотрите результат в workspace, рассылаете отчёты команде.

Gradle plugin scan

Отправляет дерево зависимостей и SBOM в DGViz. Исходный код на сервер не попадает.

CVE sync

Фоновая синхронизация NVD, OSV, GHSA (и опционально Snyk) с настраиваемым cron.

Workspace & ACL

Доступ к проектам через группы. Пользователи видят только свои репозитории и сканы.

Отчёты и почта

Экспорт PDF/CSV/XLSX/TXT и рассылка участникам группы с доступом к репозиторию.

Invite без пароля

Админ создаёт пользователя — на email уходит ссылка для самостоятельной установки пароля.

Docker & GHCR

Compose для локального запуска; релизные образы публикуются в GitHub Container Registry.

Быстрый старт

Три шага от нуля до первого скана.

Поднять стек

docker compose up --build — UI на :8080, логин admin/admin.

Создать репозиторий

Admin → Repositories: скопируйте repositoryId и scan token.

Запустить плагин

В проекте: id("io.github.dgviz.scan") и ./gradlew dgvizScan.
