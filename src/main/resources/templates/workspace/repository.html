Первый раз / при смене зависимостей: ./gradlew dgvizScan

Пересканировать в UI повторно анализирует уже сохранённый SBOM/дерево по актуальной CVE DB — плагин не нужен. Плагин (или «Обновить дерево (CI)») нужен только чтобы обновить сам состав зависимостей.

Параметры Gradle-плагина dgviz { }

ПараметрОбяз.По умолчаниюОписание
hostдаhttp://localhost:8080Базовый URL DGViz (без завершающего /).
repositoryIdда—ID репозитория из Admin → Репозитории.
tokenда—Scan token репозитория; заголовок X-DGViz-Token.
createIssuesнетfalseСоздавать issues в GitLab/GitHub для critical/high CVE (нужен access token в DGViz).
failOnIssuesнетtrueПадать задачей dgvizScan, если отчёт со статусом FAILED.
configurationNameнетruntimeClasspathGradle configuration для дерева (нужен Java/Java Library plugin).

Задача: dgvizScan (group verification). Отчёты: build/reports/dgviz/report.md, report.json. Env: DGVIZ_HOST, DGVIZ_REPO_ID, DGVIZ_TOKEN, DGVIZ_CREATE_ISSUES. Подробнее: dgviz-gradle-plugin/README.md.
